TRANSPARENCY FIRST

Security, explained.

Keamanan adalah proses berkelanjutan, bukan janji absolut. Ini yang dilakukan hub ini.

⌑

Backend proxy

Browser hanya memanggil endpoint milik hub. URL provider dan pemanggilan upstream berada di server.

ENABLED
⏱

Rate limiting

Endpoint API memiliki batas request per IP untuk mengurangi spam dan penyalahgunaan.

ENABLED
◈

Minimal data

Email dan magic link tidak disimpan di database atau dicatat ke log aplikasi. Gunakan HTTPS saat deploy.

DESIGNED
!

Third-party risk

Provider tetap menerima data yang dibutuhkan untuk menjalankan permintaan. Hub ini tidak bisa menjamin keamanan atau ketersediaan provider.

PLEASE NOTE
!
Apakah web ini 100% aman?

Tidak ada aplikasi online yang bisa dijamin 100% aman. Sebelum produksi, gunakan HTTPS, batasi ALLOWED_ORIGINS, simpan secrets hanya di environment server, dan tinjau kebijakan provider. Jangan gunakan untuk akun orang lain.
